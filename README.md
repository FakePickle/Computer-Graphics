# Computer Graphics Projects

This repository contains three assignments completed as part of the Computer Graphics course at Indraprastha Institute of Information Technology, Delhi. Each project demonstrates various aspects of computer graphics implementation using C++, OpenGL, and related libraries.

## Projects Overview

1. [Interpolating Piecewise Quadratic Bezier Curves](#1-interpolating-piecewise-quadratic-bezier-curves)
2. [Transformations, Viewing, and Projections](#2-transformations-viewing-and-projections)
3. [Lighting and Shading](#3-lighting-and-shading)

## 1. Interpolating Piecewise Quadratic Bezier Curves

This project implements interpolating piecewise quadratic Bezier curves with G1 continuity.

### Key Features:
- Interactive addition and modification of control points
- Real-time calculation of Bezier curves with G1 continuity
- Visualization using OpenGL and ImGui

### Technologies:
- C++
- OpenGL
- ImGui

[View detailed report](https://github.com/FakePickle/Computer-Graphics/blob/main/Assignment01/CG_Assignment_1.pdf)

## 2. Transformations, Viewing, and Projections

This project focuses on 3D transformations, custom viewing functions, and various perspective projections.

### Key Features:
- Rotation of a 3D cube about an arbitrary axis
- Custom implementation of the lookAt function
- Four different perspective views: one-point, two-point, and two three-point perspectives

### Technologies:
- C++
- OpenGL
- GLM (OpenGL Mathematics library)

[View detailed report](https://github.com/FakePickle/Computer-Graphics/blob/main/Assignment02/CG_Assignment_2.pdf)

## 3. Lighting and Shading

This project implements various lighting and shading techniques on a 3D sphere.

### Key Features:
- Multiple lighting and shading modes including:
  - Colored Normals
  - Gouraud Shading
  - Phong Shading
  - Spotlight effects
  - Headlight with moving camera
- Interactive camera movement and object rotation

### Technologies:
- C++
- OpenGL
- GLFW
- GLM
- ImGui

[View detailed report](https://github.com/FakePickle/Computer-Graphics/blob/main/Assignment03/CG_Assignment_3.pdf)

## Getting Started

Each project folder contains its own set of files and instructions. Please refer to the individual project reports for detailed information on setup, compilation, and usage.

- C++ compiler

1. Clone this repository
